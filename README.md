## 🇨🇳 中文

把科学、人文、历史、社会科学、教材片段或课程材料转成极简线条小人图解科普视频。默认交付是完整成片而不是课堂练习，第一份产出是可直接投产的制作方案文本文件，覆盖需求理解、视频生成方案、口播脚本、图解系统、分镜脚本、主视觉方向、素材与生产计划、事实核查备注。流程采用逐步确认：每个大步骤结束都弹交互卡片，推荐项排第一，支持修改当前步骤或继续下一步；用户说“自动继续”时只在主视觉、分镜、视频生成、旁白、最终合成等高成本节点确认。视觉风格固定为极简线条小人加信息图，线条、箭头、时间线、地图、对比框共同承担解释任务。

### ✨ 能做什么

- 知识点/教材片段 → 完整科普成片，默认 60 秒 16:9 横屏
- 需求理解四件套：主题、类型、输出形式、受众一次对齐
- 8 种讲解结构可选：时间线、因果链、纠正误解、对比讲解等
- 口播脚本按 0-6 / 6-15 / 15-35 / 35-50 / 50-60 秒节奏写
- 分镜按内容动态定镜数：20-30 秒 2-4 镜，60 秒 5-8 镜，一镜一个微观点
- 图解系统统一图标/标签/强调色，关键帧先给运动计划，成片默认配字幕

## 🇬🇧 English

Turns science, humanities, history, social-science, textbook, or course material into a minimalist line-doodle infographic explainer video. The default goal is a finished film rather than a classroom exercise, and the first deliverable is a production-plan text file ready for media generation, covering the requirement brief, video plan, narration script, diagram system, storyboard, key-visual direction, asset/production plan, and fact-check notes. The flow confirms step by step: every major stage ends in an interactive card with the recommended option first, so the user can revise that stage or continue; say "auto-continue" and it only pauses at high-cost nodes such as key visual, storyboard, video generation, narration, and final compositing. The locked visual identity is minimalist line figures plus infographics, where lines, arrows, timelines, maps, and comparison boxes carry the explanation.

### ✨ What it does

- Knowledge point or textbook excerpt to a finished explainer, default 60s 16:9
- Four-part brief in one pass: topic, type, output form, audience
- Eight explanation structures to pick from: timeline, causal chain, myth-busting, comparison
- Narration scripted to a 0-6 / 6-15 / 15-35 / 35-50 / 50-60s beat map
- Shot count scales with content: 2-4 shots for 20-30s, 5-8 for 60s, one idea per shot
- Unified icons, labels, accent colors, plus a keyframe motion plan and burned-in subtitles
